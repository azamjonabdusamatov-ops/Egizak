# Egizak

Рекламасиз, кўп клонли Android программа. Битта программанинг исталганча нусхасини (WhatsApp 1, 2, 3…) алоҳида маълумотлар билан ишга тушириш.

- Режа ва архитектура: [docs/PLAN.md](docs/PLAN.md)
- Ҳолати: 1-босқич. NewBlackbox движоги (Apache-2.0) `engine/` папкасига git submodule сифатида уланган.
- Махфийлик: движокнинг носозлик логларини ташқи серверга юбориш функцияси ўчирилган.

Йиғиш: `git clone --recursive`, кейин Android Studio'да очинг ёки `./gradlew assembleDebug` (JDK 21, NDK 29).

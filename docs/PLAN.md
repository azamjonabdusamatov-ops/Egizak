# Egizak — рекламасиз, кўп клонли Android программа (режа)

> «Egizak» — вақтинчалик иш номи (ўзбекча «эгизак»). Хоҳлаган пайт ўзгартирса бўлади.

## 1. Мақсад

- Ҳар қандай ўрнатилган программанинг **бир неча** нусхасини (клонини) яратиш: WhatsApp 1, WhatsApp 2, WhatsApp 3…
- Ҳар бир клоннинг маълумотлари (аккаунт, чатлар, кеш) бир-биридан алоҳида.
- **Реклама йўқ**, трекер йўқ, аналитика SDK йўқ.
- Root талаб қилинмайди.

## 2. Архитектура вариантлари

| Ёндашув | Нечта клон | Root | Мураккаблиги | Хулоса |
|---|---|---|---|---|
| **A. Виртуализация движоги** (VirtualApp услубида: программани ўз процессимиз ичида «виртуал» ишга тушириш) | Чексиз (ҳар клон = алоҳида виртуал `userId`) | Йўқ | Юқори, Android ҳар янгиланганда мослаш керак | **Танланади** |
| B. Android Work Profile (Island/Shelter каби, `DevicePolicyManager`) | Фақат **1 та** (тизим битта иш профилига рухсат беради) | Йўқ | Паст, барқарор | Талабга жавоб бермайди |
| C. Тизим кўп-фойдаланувчи режими (secondary users) | Бир неча | Тизим ҳуқуқи керак | — | Оддий программа учун ёпиқ |

**Хулоса:** «бир неча клон» талаби фақат A варианти билан бажарилади. Бозордаги Parallel Space / Dual Space каби программалар ҳам шу йўлдан борган.

### Қайси движок?

- **NewBlackbox** (github.com/ALEX5402/NewBlackbox) — BlackBox движогининг янгиланган тармоғи. Лицензияси **Apache-2.0** (тижорий фойдаланиш, ўзгартириш эркин; фақат копирайт ва NOTICE сақланади). Android 5–14+, ARM64/ARMv7/x86. API'да ҳар бир `installPackageAsUser(pkg, userId)` чақируви алоҳида изоляцияланган нусха яратади — бизга айнан шу керак.
- VirtualApp (asLody) — асл лойиҳа, лекин очиқ версияси эскирган, янги версиялари тижорий.
- VirtualXposed — Xposed'га йўналтирилган, GPL; бизга ортиқча.

**Танлов: NewBlackbox ни git submodule сифатида `engine/` папкасига улаймиз**, ўзимизнинг UI'мизни устига қурамиз. Движок `CloneEngine` интерфейси орқали ажратилган, керак бўлса кейин алмаштирса бўлади.

## 3. Хавф ва чекловлар (олдиндан билиш керак)

1. **Google Play.** Бундай программалар Play сиёсатига тўқнаш келиши мумкин (бошқа программа кодини юклаш). MVP'ни **APK сифатида тўғридан-тўғри** тарқатамиз; Play'га кейин алоҳида баҳолаймиз.
2. **Мослик.** Баъзи программалар виртуал муҳитни аниқлайди ва ишламайди (банк программалари, баъзи ўйинлар, Play Integrity талаб қилувчилар). WhatsApp, Telegram, Instagram, Facebook — одатда ишлайди, лекин ҳар бир Android версиясида синаш керак.
3. **Android 15/16.** Ҳар янги версия движокни бузиши мумкин; движокни янгилаб туриш доимий иш.
4. **Хотира.** Ҳар клон алоҳида маълумот жойини эгаллайди.

## 4. MVP (биринчи версия) таркиби

1. Телефондаги ўрнатилган программалар рўйхати (тизим программаларисиз), қидирув.
2. «Клон қўшиш» — танланган программанинг янги нусхасини яратиш (кетма-кет `userId` 0, 1, 2…).
3. Клонлар рўйхати: номи («Telegram 2»), белги устида рақам.
4. Клонни ишга тушириш, ўчириш, маълумотини тозалаш, номини ўзгартириш.
5. Клон учун уй экранига ёрлиқ (shortcut) қўшиш.
6. Ўзбек (кирилл/лотин), рус, инглиз тиллари.

**MVP'га кирмайди (кейин):** клонга парол/қулф, GPS алмаштириш, қурилма маълумотини алмаштириш, Play'да чоп этиш.
